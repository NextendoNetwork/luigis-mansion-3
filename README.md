# luigis-mansion-3

NEX game server for Luigi's Mansion 3, built on the NextendoNetwork [nextendo-nex](https://github.com/NextendoNetwork/nextendo-nex) core.
See `example.env` for configuration. Not affiliated with Nintendo.

`go.mod` uses a `replace` directive to the sibling `../nextendo-nex` checkout — clone both side by side to build.
